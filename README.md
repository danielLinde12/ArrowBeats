# ArrowBeats ♫

A rhythm game built in Processing.js. Arrows scroll toward a row of targets in time with the music. Press the matching key as each arrow lines up to score points. Miss too many and it's game over.

## How to play

| Key | Arrow |
| --- | --- |
| `W` | Up |
| `A` | Left |
| `S` | Down |
| `D` | Right |

Press the key when an arrow reaches its target. Your score and misses show in the corner.

## Levels

| Level | Song | Misses allowed |
| --- | --- | --- |
| 1 | Brainstorm | 30 |
| 2 | Powerup | 25 |
| 3 | Critical | 20 |

Each level gives you less room for error than the one before.

## Features

- Title, level select, help, and game-over screens with clickable buttons
- Three levels, each synced to its own song
- Live score and miss counter
- Hit detection that checks whether the right key was pressed while an arrow overlapped its target

## Built with

- Processing.js (JavaScript)
- Lo-fi cityscape backgrounds and royalty-free 8-bit music, loaded through GitHub Pages
